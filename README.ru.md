# codex-app-mcp

[English](README.md) · [Русский](README.ru.md)

**Управляйте задачами Codex из своего MCP-клиента: запускайте работу, следите за результатом и возвращайтесь к ней позже.**

Мост подключает ассистента к установленному Codex app-server. Подходит для задач разработки, ревью и сохраняемых целей: можно задать бюджет, уточнить запрос и получить результат через единый интерфейс. Авторизация и использование моделей остаются в Codex.

## Что можно делать

- Создавать и продолжать задачи, управлять целями и бюджетом работы.
- Проходить задачи по шагам с помощью навигатора `codex_app_session_next`.
- Работать с файлами и командами в разрешённых проектах, запускать ревью.
- Настраивать очереди, расписания и дополнительные права через MCP-интерфейс.

Доступные методы зависят от установленной версии Codex и политики сервера. Это независимый, неофициальный проект; он не связан с OpenAI, Codex, Anthropic или xAI. Не переносите OAuth-токены в конфигурацию MCP: вход выполняется локально через `codex login`.

## Установка

Нужны Python 3.10+, Git и установленный Codex CLI. Начните с [пошагового руководства](docs/EASY.md): там находятся команды установщика для Windows и macOS/Linux. Укажите конкретный проект, к которому разрешаете доступ. Параметр установщика для этого — `--project` на macOS/Linux и `-Project` в PowerShell.

Выполните `codex login` под тем же пользователем ОС, который запускает MCP. На macOS/Linux установщик готовит фрагмент `~/.config/codex-mcp/mcp/claude_desktop.snippet.json`; добавьте его в конфигурацию клиента. Проверка:

```sh
source ~/.config/codex-mcp/env
~/.local/share/codex-mcp/.venv/bin/python ~/.local/share/codex-mcp/scripts/probe_stdio.py
```

На Windows команда устанавливается в `%LOCALAPPDATA%/codex-mcp/.venv/Scripts/`. Добавьте в MCP-клиент запись, заменив оба пути на свои:

```json
{
  "mcpServers": {
    "codex": {
      "command": "C:/Users/you/AppData/Local/codex-mcp/.venv/Scripts/codex-app-mcp.exe",
      "env": {"CODEX_APP_MCP_ALLOWED_ROOTS": "C:/Users/you/code/my-project"}
    }
  }
}
```

После подключения перезапустите MCP и начните с запроса:

> Покажи статус Codex, разрешённые каталоги проектов и доступные задачи. Пока ничего не запускай.

`codex_app_status` показывает подключение и действующую политику. Затем обычный цикл: `codex_app_session_begin` с целью → выполнение карточек `codex_app_session_next` → при `done=true` завершение через `codex_app_session_end`.
