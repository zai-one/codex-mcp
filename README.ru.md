# Codex app-server MCP

[English](README.md) · [Русский](README.ru.md)

**Управляйте задачами Codex из своего MCP-клиента: запускайте работу, следите за результатом и возвращайтесь к ней позже.**

Сервер подключает ассистента к одному постоянному процессу `codex app-server`. Подходит для команд, которым нужны несколько задач разработки, ревью, работа с ветками и расписания через единый интерфейс. Установленный Codex остаётся обязательной зависимостью; авторизация выполняется в самом Codex.

## Что можно делать

- Создавать задачи и ходы, уточнять запрос, прерывать, разветвлять и архивировать работу.
- Ставить сохраняемые цели с выбором модели, уровня рассуждения и бюджета токенов.
- Запускать ревью, команды и работу с файлами в разрешённых каталогах.
- Управлять очередью заданий, рабочими деревьями Git и расписаниями с часовыми поясами.
- Обрабатывать подтверждения, вопросы пользователю и вызовы других MCP через списки разрешений.

Также доступны аудит, метрики, восстановление работы и типизированный каталог экспериментального протокола. В него входят файловые методы v2, вызовы разрешённых MCP/SaaS и `process/*`, для которых отдельно нужен полный доступ к хосту. Подробности — в [справочнике](docs/REFERENCE.md).

Возможности зависят от установленной версии Codex. Сервер получает каталог протокола из вашего бинарного файла, а не предполагает наличие новых методов.

## Начать работу

Установите и авторизуйте Codex, затем клонируйте этот репозиторий. Windows PowerShell:

```powershell
git clone https://github.com/zai-one/codex-mcp.git
cd codex-mcp
py -3 -m pip install -e ".[test]"
```

macOS / Linux:

```sh
git clone https://github.com/zai-one/codex-mcp.git
cd codex-mcp
python3 -m pip install -e ".[test]"
```

В настройках MCP-клиента укажите команду `codex-app-mcp`. Через переменную `CODEX_APP_MCP_ALLOWED_ROOTS` задайте каталоги, с которыми разрешено работать. Например, для Windows:

```json
{
  "mcpServers": {
    "codex": {
      "command": "codex-app-mcp",
      "env": {"CODEX_APP_MCP_ALLOWED_ROOTS": "D:\\Projects\\my-app"}
    }
  }
}
```

На macOS/Linux замените путь проекта на абсолютный путь вашей системы. Команда должна быть доступна процессу клиента; при необходимости укажите абсолютный путь к установленному исполняемому файлу. Перезапустите MCP-подключение и начните с запроса:

> Покажи доступные возможности Codex и текущие задачи. Пока ничего не запускай.

`codex_app_status` показывает подключение и действующую политику. Пути закрыты, пока не настроен список разрешённых каталогов. Полный доступ к машине и изменяющие состояние административные RPC включаются отдельно. Описание этих настроек, HTTP с bearer-токеном и проверки установки — в [полном руководстве](README.md#install) и [справочнике](docs/REFERENCE.md).
